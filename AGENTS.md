# AGENTS.md — rules for local agents (opencode / Qwen)

You are a junior assistant on this repo. A senior reviewer checks every diff
you produce. Do exactly the task you were given — nothing more. If you are
unsure, stop and say what you're unsure about instead of guessing.

## Boundaries (hard rules)

- Only read and modify files **inside this repository**.
- NEVER modify these (generated or golden — regenerated by scripts only):
  - `game/data/`, `game/src/p64/`, `game/Makefile`, `game/project.p64proj`
  - `tests/vectors/`, `game/rawfs/model.bin`, `game/src/user/selftestGolden.h`
- Never run `git commit`, `git push`, `git checkout`, or `git reset`.
- Never delete or move files. Never install software. No network access.

## Code rules

- `core/` is the inference engine: flat directory, `.cpp`/`.h` files only,
  C-style C++. **No floats, no heap, no exceptions/RTTI, no libdragon
  includes.** Integer math only.
- The NGPT blob is big-endian and parsed byte-by-byte with
  `ngpt_read_u16be`/`ngpt_read_u32be`. Never cast buffer pointers to wider
  integer types.
- The streaming API (`ngpt_load → ngpt_reset → ngpt_step → NGPT_EOS`) is
  frozen — do not change its signatures.

## Build / test

```sh
cmake -B build tests -DNGPT_SANITIZE=OFF
cmake --build build
ctest --test-dir build --output-on-failure
```
