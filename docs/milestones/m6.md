# M6 — Real hardware (ROM v1.0 on a real N64 via EverDrive)

**Status: ready to execute — needs Luke + the console.** Everything
that can be prepared without hardware is done. This doc is what a
fresh session (or a human) needs to finish the project.

## Where the project stands (start-of-M6 snapshot, 2026-07-16)

- M0–M5 shipped, tagged (`m0`..`m5`), pushed. ROM v1.0-rc = tag `m5`:
  sampled GRU (H=128, ~68K params), SELFTEST PASS in Ares, sustained
  60 chars/sec at 60 VPS. Full trail: README status + docs/milestones/.
- Test ROMs for the EverDrive are staged on the dev machine's Desktop:
  `m2/m3/m4/m5_64gpt.z64` (+ `rsp_spike_64gpt.z64`, see below).
- **RSP spike succeeded** (docs/spikes/rsp-matvec.md, branch
  `spike/rsp-matvec`, unmerged): the full GRU matvec runs on the RSP
  bit-exactly at 2.8× CPU speed, unoptimized. Not part of v1.0 —
  it is the strongest post-1.0 direction, alongside the M7 vision
  (docs/ideas-m7-living-npcs.md).
- **M6.1 shipped (2026-07-16, after this snapshot): the RSP path is
  adopted** — ROM v1.1 (`versions/m6_1_64gpt.z64`, also staged on the
  Desktop) runs the demo's inference through the RSP at 4.8ms/char vs
  10.3ms, SELFTEST + CPU-vs-RSP cross-check on screen at every boot,
  no more black-screen wait. Details: docs/milestones/m6.1.md. On the
  console, prefer booting this one — it supersedes the spike ROM's
  60-second validation (same kernel, now in the real demo).
