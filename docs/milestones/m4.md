## What changes vs M3 (and what doesn't)

Same blob format (type 1), same frozen streaming API, same priming
protocol (`NPC=… MOOD=… EV=…|`). Three things change:

1. **Corpus** is generated, not hand-written:
   `trainer/ngpt_trainer/corpus_gen.py` (contract 004) — deterministic
   template grammar, per-NPC voice, ≥200 distinct responses per combo.
2. **Model** grows to ~100K params: `H = 128`, `V` = generated charset
   (≤ 96 cap). Trained with mini-batches + train/val split, not
   full-batch overfit.
3. **Sampling**: generation draws from the distribution instead of
   argmax. Deterministic given the seed ⇒ self-test stays exact.

## Sampler design (integer, bit-exact both sides — signed off by Luke 2026-07-15)

**Blob format unchanged (type 1).** The exp2 LUT is fixed math, not
learned weights: the trainer emits the identical 256-entry table into
`core/ngpt_sampler_lut.h` and `ngpt_trainer/sampler_lut.py` from one
script (the selftestGolden.h no-drift pattern). Sampler params
(temperature, k, seed) are runtime config pinned by the goldens, not
blob fields.

- PRNG: xorshift32 (`x^=x<<13; x^=x>>17; x^=x<<5`, u32), seed in the
  ctx; the ROM self-test uses a fixed seed, the demo reseeds from the
  frame counter.
- Temperature: reciprocal multiply — `scaled = rshift_round(logit *
  inv_t_q8, 8)` with `inv_t_q8 = round(256/T)`; T=1 is inv_t=256.
- Weights: `w_i = lut_exp2(scaled_i - scaled_max)` over [-16, 0) in the
  LUT's fixed input format; indices outside top-k get w=0. Ties toward
  the lowest id everywhere, matching np behavior.
- Draw: `r = xorshift32() % total_weight`; emit the first index whose
  cumulative weight exceeds r.
- k=1 must reproduce M3-style argmax exactly — it stays the self-test's
  fallback mode.

## Gotchas (what M5 should know)

- **The exp2 LUT wants floor, not round.** Round-half-up gives the
  deep-tail bucket weight 1, making "tiny temperature = greedy" only
  almost-true (1-in-31k misses). Floor makes entries 0..15 exactly zero
  and the property exact. Caught by test_tiny_temperature_is_greedy.
- **LUT domain off-by-2×.** First mapping (`>>7` over ±16) silently
  covered [-16,+16): diff 0 landed mid-table and near-ties got fat
  weights — sampling was far too hot. The [-16,0) mapping is `clamp to
  [-16384,-1]` then `>>6`. Same test caught it.
- **Temperature is base-2 here** (exp2 weights): T_natural ≈ 0.69 ×
  T_base2. INV_T_Q8=384 ≈ natural T 0.46.
- **One conditioning miss lives in the goldens:** WIZARD/CALM/THEFT
  answers with festival imagery at this seed — right voice, wrong event.
  Kept deliberately: it is honest ~68K-param behavior, and the self-test
  pins behavior, not correctness of manner.
- **Delegation:** corpus_gen escalated after 3 worker attempts (fixed
  sentences, no slots — see .ai/tasks/004). The contract itself also had
  an unsatisfiable size criterion (734KB max vs 1MB min) — sanity-check
  contract arithmetic before dispatch.
